# 高校物理ビジュアル学習アプリ

日本の高校物理(主に**物理基礎**、一部「物理」)の基本法則を、
「式 → 数値代入 → グラフ・運動のようす」のつながりで視覚的に学ぶための単一HTMLアプリです。

## 動かし方

`index.html` をブラウザで開くだけです。ビルドやサーバーは不要です(依存ライブラリなし・オフラインで動作)。

## 使い方

1. 上部のタブから単元を選ぶ
2. スライダーで物理量(初速度・加速度・質量・波長など)を変える
3. **式に代入された数値・グラフ・アニメーションがすべて連動して**リアルタイムに変化する

各単元に ▶ 再生 / ⏸ 一時停止 / リセット ボタンがあります。

## 収録単元

| タブ | 科目 | 単元 | 主な式 | 見どころ |
| --- | --- | --- | --- | --- |
| 等加速度直線運動 | 物理基礎 | 運動の表し方 | v = v₀ + at, x = v₀t + ½at² | v-tグラフの**面積=変位**を塗りつぶしで表示 |
| 放物運動 | 物理 | 平面内の運動 | x = v₀cosθ·t, y = v₀sinθ·t − ½gt² | 速度の水平・鉛直成分をベクトルで分解表示 |
| 力学的エネルギー | 物理基礎 | 仕事とエネルギー | mgh = ½mv² + mgh′ | K・U・E の棒グラフで**保存則**を確認 |
| 単振動 | 物理 | 円運動と単振動 | x = A sin ωt, T = 2π√(m/k) | 振幅を変えても周期が変わらない(等時性) |
| 波 | 物理基礎 | 波の性質 | v = fλ | **y-xグラフとy-tグラフの区別**、媒質は上下に振動するだけ |
| オームの法則 | 物理基礎 | 電気 | V = RI, P = VI | 回路を流れる点の速さ=電流、I-Vグラフの傾き=1/R |
