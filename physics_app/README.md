# 高校物理ビジュアル学習アプリ

日本の高校物理(主に**物理基礎**、一部「物理」)の基本法則を、
「式 → 数値代入 → グラフ・運動のようす」のつながりで視覚的に学ぶための単一HTMLアプリです。

## 動かし方

`index.html` をブラウザで開くだけです。ビルドやサーバーは不要です(依存ライブラリなし・オフラインで動作)。

## 使い方

1. 上部のタブから単元を選ぶ
2. スライダーで物理量(初速度・加速度・質量・波長など)を変える
3. **式に代入された数値・グラフ・アニメーションがすべて連動して**リアルタイムに変化する

各単元に ▶ 再生 / ⏸ 一時停止 / リセット ボタンがあります。

## 収録単元

| タブ | 科目 | 単元 | 主な式 | 見どころ |
| --- | --- | --- | --- | --- |
| 等加速度直線運動 | 物理基礎 | 運動の表し方 | v = v₀ + at, x = v₀t + ½at² | v-tグラフの**面積=変位**を塗りつぶしで表示 |
| 放物運動 | 物理 | 平面内の運動 | x = v₀cosθ·t, y = v₀sinθ·t − ½gt² | 速度の水平・鉛直成分をベクトルで分解表示 |
| 力学的エネルギー | 物理基礎 | 仕事とエネルギー | mgh = ½mv² + mgh′ | K・U・E の棒グラフで**保存則**を確認 |
| 単振動 | 物理 | 円運動と単振動 | x = A sin ωt, T = 2π√(m/k) | 振幅を変えても周期が変わらない(等時性) |
| 運動量保存 | 物理 | 運動量の保存 | m₁v₁ + m₂v₂ = m₁v₁′ + m₂v₂′ | 反発係数 e と運動エネルギーの増減、x-tグラフの折れ曲がり=衝突 |
| 運動量とエネルギー | 物理 | 力積と仕事・保存則の使い分け | FΔt = Δp, Fx = ΔK | 3実験の切り替え式:衝突での保存の違い/正面衝突(合計ゼロの運動量)/同じ力で「同じ時間」vs「同じ距離」押す比較 |
| 波 | 物理基礎 | 波の性質 | v = fλ | **y-xグラフとy-tグラフの区別**、媒質は上下に振動するだけ |
| 定常波 | 物理基礎 | 音(弦・気柱) | λ = 2L/n, 4L/(2n−1) | 節と腹の位置、**閉管は奇数倍振動のみ** |
| ドップラー効果 | 物理 | 音の伝わり方 | f′ = fV/(V − v_s) | 波面のアニメーションで前方の波長圧縮を観察 |
| レンズ | 物理 | 光 | 1/a + 1/b = 1/f | 3本の代表光線の作図、実像⇔虚像の切り替わり |
| 熱量の保存 | 物理基礎 | 熱 | m₁c₁(t₁−T) = m₂c₂(T−t₂) | 温度-時間グラフが平衡温度に収束するようす |
| ベルヌーイの定理 | 物理(発展) | 流体 | A₁v₁ = A₂v₂, P + ½ρv² = 一定 | ベンチュリ管:粒子の流れ・液柱圧力計・圧力の色分けが連動 |
| オームの法則 | 物理基礎 | 電気 | V = RI, P = VI | 回路を流れる点の速さ=電流、I-Vグラフの傾き=1/R |
| 電磁誘導 | 物理 | 電磁誘導 | V = vBl, V = ΔΦ/Δt | 磁束の増加とΦ-tグラフの傾き=起電力、レンツの法則 |
| 確認クイズ | 共通 | 全単元 | — | 数値がランダムに変わる4択問題を毎回10問出題、解説付き |

## 発展・読み物タブ(高校範囲外)

物理初心者でも読めるよう、高校物理の知識だけを前提に章立てのストーリーで最先端まで案内します。
各章にインタラクティブなシミュレーションが付属し、2つの物語は最終章で相互にリンクします。

| タブ | 章立て | 内容 |
| --- | --- | --- |
| モルの計算(化学基礎) | 全8章 | なぜmolが必要か(水滴の分子数)→ アボガドロ定数(数のスケール比較)→ モル質量(原子量の足し算・分子の可視化)→ 換算の三角形(質量⇄mol⇄粒子数)→ 気体22.4 L/molとPV=nRT → モル濃度 → 化学反応式の量的関係(限定反応物・質量保存)→ まとめとつまずきポイント |
| 超ひも理論への道 | 全8章 | 物質の階層(ズーム可視化)→ 点粒子の無限大 → ひもの振動=粒子(定常波とのつながり)→ E=mc²と質量 → 重力子 → 余剰次元(ホースのたとえ)→ 検証の壁 → まとめ |
| 繰り込みへの道 | 全8章 | 電場のエネルギー → 電子の自己エネルギー発散 → 泡立つ真空(仮想粒子)→ 真空偏極と電荷の遮蔽 → 繰り込み(カットオフと裸の質量の可視化)→ 走る結合定数 → 繰り込み可能性と量子重力 → まとめ |
