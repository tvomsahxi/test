# マインドマップアプリ 外部仕様書

アプリを「使う人」の視点から、画面・操作・データの扱いを定義する文書です。
(実装の内部構造については [内部仕様書](internal_spec.md) を参照)

## 1. アプリの目的

起きた問題やテーマを「起点」として、そこから連なる考え(原因・気づき・対策)を
四角(ノード)のつながりとして書き出し、後から振り返れるようにするアプリ。

- 思いついた瞬間に、タップだけで思考を枝分かれさせて記録できること
- 記録が自動で残り、一覧からいつでも振り返れること
- 記録を外部(バックアップ・生成AI・他人への共有)に持ち出せること

を主眼とする。

## 2. 動作環境

| 項目 | 内容 |
| --- | --- |
| プラットフォーム | Android / iOS / Web(Flutter による共通実装) |
| ネットワーク | 不要(完全オフラインで動作) |
| アカウント | 不要 |
| データ保存先 | 端末内のみ(外部送信はユーザーが共有操作をしたときだけ) |
| 表示言語 | 日本語 |

## 3. 画面一覧

| # | 画面名 | 役割 |
| --- | --- | --- |
| 1 | ホーム画面 | マップの一覧表示・新規作成・削除・保存/エクスポートの入口 |
| 2 | キャンバス画面 | マインドマップの編集(四角の追加・編集・移動・削除) |
| 3 | リスト(振り返り)画面 | マップ全体をインデント付きリストで表示・テキストコピー |
| 4 | エクスポート画面 | 書き出したテキストのプレビュー・コピー・共有 |
| 5 | 復元(インポート)画面 | バックアップJSONの貼り付け・読み込み・取り込み方の選択 |

画面遷移:

```
ホーム ──作成/一覧タップ──▶ キャンバス ──≡──▶ リスト
  │                              
  ├──≡(一覧の各行)──▶ リスト
  └──保存ボタン──▶ 選択シート ──▶ エクスポート画面 / 復元画面
```

## 4. 画面仕様

### 4.1 ホーム画面

- **タイトル入力欄**(最大60文字)と**「作成」ボタン**
  - 起点となる文字を入力して「作成」を押すと、新しいマップが作られてキャンバス画面へ遷移する
  - 入力が空のときは何も起きない
- **マップ一覧**(更新日時の新しい順)
  - 各行に「タイトル」「四角の数 ・ 更新日時」を表示
  - 行タップ → キャンバス画面を開く
  - ≡ ボタン → リスト画面を開く
  - ゴミ箱ボタン → 確認ダイアログ(「◯◯を削除しますか?」)を経て削除
- マップが1つもないときは案内文を表示
- **右上の保存ボタン** → 「保存・エクスポート」選択シートを開く(4.4参照)

### 4.2 キャンバス画面

新規作成直後は、タイトルの文字が入った**ルートの四角**が画面中央に1つ置かれた状態から始まる。

| 操作 | 動作 |
| --- | --- |
| 四角をタップ | 入力ダイアログ「つながる内容を入力」が開き、「追加」でその四角につながる新しい四角ができる(空欄・キャンセルなら何もしない) |
| 四角を長押し | メニュー(テキストを編集/この四角を削除(枝ごと))を表示。ルートの四角に削除項目は出ない |
| 四角をドラッグ | 四角を移動(つながる線は追従) |
| 背景をドラッグ | キャンバス全体を移動(パン) |
| ピンチ | ズーム(0.35倍〜2.5倍) |
| 右上 ≡ ボタン | リスト画面を開く |
| 右上 🎯 ボタン | 表示位置を中央(ルート付近)に戻す |

- 新しい四角は、親の四角から見て**空いている方向に自動配置**される(ルートの子は上から時計回り、それ以外は親の伸びている方向を中心に左右へ振り分け)。位置は後からドラッグで自由に変えられる
- 親子の四角は曲線で結ばれる
- テキスト編集でルートの文字を変えると、マップのタイトルも変わる
- 枝ごと削除で複数の四角が消える場合は「この四角と、つながるN個の四角も削除されます」と確認する
- 画面下部に操作ヒント(「四角をタップ → つながる四角を追加 / 長押し → 編集・削除」)を約5秒間表示
- 変更(追加・編集・削除・移動)はその都度**自動保存**される

### 4.3 リスト(振り返り)画面

- マップ全体を、起点を先頭にした**インデント付きリスト**で表示する
  - 並び順:枝を深さ優先でたどった順(四角を追加した流れに近い順)
  - インデントの深さ=枝の深さ
- 上部に「作成 ◯◯ ・ 更新 ◯◯」の日時を表示
- 右上のコピー ボタンで、以下の形式のテキストをクリップボードにコピーし「リストをコピーしました」と表示する

```
- 起点のテキスト
  - 子のテキスト
    - 孫のテキスト
  - 別の子
```

(四角の中の改行は空白1つに置き換える)

### 4.4 保存・エクスポート(選択シート)

ホーム画面右上の保存ボタンで開く。3つの選択肢がある。

#### (1) JSONでバックアップ

全マップを**復元可能なJSON**として書き出す。エクスポート画面(4.5)でプレビューされる。

出力形式:

```json
{
  "app": "mindmap_app",
  "format": "mindmap-backup",
  "version": 1,
  "exportedAt": "2026-07-18T15:30:00.000",
  "mapCount": 2,
  "maps": [ (アプリ内部の保存形式そのまま) ]
}
```

#### (2) AI分析用にエクスポート

全マップを**生成AIに貼り付けて分析を頼める形のMarkdown**として書き出す。

- 冒頭:データの説明(起点・枝・インデントの意味)と、分析してほしい観点
  (思考パターンの癖/問題発生時の判断の傾向/対策の立て方と抜けやすい視点/アドバイス)
- 本文:マップを**作成日順**に並べ、それぞれ
  `## マップN: タイトル`、作成/更新日時と四角の数、インデント付きアウトライン

#### (3) バックアップから復元

復元画面(4.6)を開く。

- (1)(2) はマップが1つもないとき「まだマインドマップがありません」と表示して開かない。(3) はいつでも開ける

### 4.5 エクスポート画面

- 書き出されたテキスト全文をプレビュー表示(選択・部分コピー可)
- **「コピー」** — 全文をクリップボードへ(「コピーしました」表示)
- **「共有」** — OSの共有シートを開く(ファイル保存アプリ・メール・メッセージアプリ等へ渡せる)。共有の件名はファイル名形式(例 `mindmap-backup_2026-07-18_1530.json`)

### 4.6 復元(インポート)画面

1. バックアップJSONを貼り付ける(「クリップボードから貼り付け」ボタンあり)
2. 「読み込む」で内容を検査し、「N個のマップ(四角M個)が見つかりました」と表示
3. 取り込み方を選ぶ:
   - **追加して取り込む(今あるマップは残す)** — 既存マップに追加。同じマップ(同一ID)が既にある場合はスキップし、「N個のマップを追加しました(M個は既にあるためスキップ)」と結果を表示
   - **全て置き換える(今あるマップは削除)** — 既存マップがある場合は「今あるN個のマップを削除して、バックアップのM個に置き換えます。よろしいですか?」の確認を挟む。実行後「N個のマップに置き換えました」と表示

エラー時のメッセージ:

| 入力 | メッセージ |
| --- | --- |
| JSONとして解釈できない | JSONとして読み取れませんでした |
| JSONだがこのアプリの形式でない | このアプリのバックアップ形式ではありません |
| maps の項目がない | バックアップにマップが含まれていません |
| マップの中身が壊れている | マップデータの読み取りに失敗しました |

## 5. データ仕様(ユーザーから見た挙動)

- 保存は**すべて自動**。明示的な保存操作は不要(保存ボタンは「書き出し」の入口)
- データは端末内にのみ保存される。アプリを削除するとデータも消える(必要ならJSONバックアップを取り共有で外部に保存しておく)
- マップ数・四角の数に明示的な上限はない

## 6. 制限事項(現バージョン)

- 端末間の自動同期はない(JSONバックアップ手動移行で代替)
- 復元画面への入力は「貼り付け」のみ(ファイル選択ダイアログはない)
- 四角どうしの線のつなぎ替え(親の変更)はできない
- 取り消し(アンドゥ)機能はない
